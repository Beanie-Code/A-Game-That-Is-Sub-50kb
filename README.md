How To Play!
#####################################

Controls.
\nAD to move left & right.
\nWASD to move menu related things.
\nTo run its SHIFT + D.
\n
\nSpace to jump & confirm letters.
\nEnter Confirms click on home menu, and brings you to home menu on Game Over.
\n
\nGraphics Are All 8x8 images excluding a few, technically one is 8x16 and one 16x8.
\nLanguage Used C

\nDownloading
\nTo Download, you'll need to download the raw file of PenguinRun2026.exe. 
\nAfter you downloaded the file, you'll find it in download folder, then double click.
\nMost likely windows will give you a warning saying, unknown publisher, you can click run anyways or, if its not there click more info Then run anyways.
\n
\nALT Download
\nHowever, if you don't feel comfortable downloading the exe(Understandable), I gave the source code titled game.c. You can take this source code download via clicking download raw. Then compile the game.
