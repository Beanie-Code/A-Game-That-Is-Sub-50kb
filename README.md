How To Play!

#####################################


Controls.

AD to move left & right.

WASD to move menu related things.

To run its SHIFT + D.


Space to jump & confirm letters.

Enter Confirms click on home menu, and brings you to home menu on Game Over.


Graphics Are All 8x8 images excluding a few, technically one is 8x16 and one 16x8.

Language Used C


Downloading

To Download, you'll need to download the raw file of PenguinRun2026.exe. 

After you downloaded the file, you'll find it in download folder, then double click.

Most likely windows will give you a warning saying, unknown publisher, you can click run anyways or, if its not there click more info Then run anyways.

ALT Download

However, if you don't feel comfortable downloading the exe(Understandable), I gave the source code titled game.c. You can take this source code download via clicking download raw. Then compile the game.

You can also check the very messy and hard to read code  too. You can even probably strip the game code, and build a Framework off of it.
